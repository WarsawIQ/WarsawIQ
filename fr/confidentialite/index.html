Rien du tout. Aucun cookie, aucun stockage local, aucun stockage de session. La page suit le réglage clair ou sombre de votre système d'exploitation, qu'elle lit mais n'enregistre jamais.

L'hébergeur, lui, voit votre requête

Autant le dire clairement, car c'est le seul endroit où des données sont traitées. Le site est servi par GitHub Pages, si bien que GitHub reçoit, et peut journaliser, les détails techniques de chaque requête – adresse IP, agent utilisateur, fichier demandé – comme le fait tout hébergeur web. C'est GitHub qui effectue ce traitement, conformément à sa déclaration de confidentialité. Nous n'avons pas accès à ces journaux et ne tenons aucune statistique de fréquentation.
