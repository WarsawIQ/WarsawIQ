Product · in pilot

AdminCloud

Small property management offices still run on binders: rent annexes calculated by hand, bank statements in folders, inspection protocols signed on paper and posted by registered mail. AdminCloud turns that archive into a ledger of buildings, units, tenants, rates and charges, and keeps it for the monthly billing that follows.

How it works

  • Photograph the archive. A phone is enough. Every page is fingerprinted and deduplicated, so the same page never enters twice.
  • A vision model reads it. Each page is classified (lease annex, bank statement, invoice, gas inspection protocol) and its fields are extracted against a schema for that document type. One photograph may carry several documents; the model is built for that.
  • Arithmetic decides what a person checks. Documents check themselves: line items must add up to the total, the amount in words must match the amount in figures, tax and bank account numbers carry checksums. A document that passes every check goes straight in. One that fails goes to a review queue, with the suspect field already marked, because we know which equation did not balance.
  • Corrections are never overwritten. Extraction writes facts, not records. Improve the model, re-run the archive, and compare the result with what a person has already accepted.

Built for money that belongs to someone else

  • Every amount has an audit trail: who changed it, when, and from what to what.
  • Rates carry validity periods and sources, so a retroactive adjustment can be reproduced years later.
  • Several offices, one system, no mixing. Every record carries the identifier of the office it belongs to, from the very first database migration, and an automated test rejects any data structure that lacks it.
  • Deletion you can check. When document scans are sent to a GPU node for reading, they live only in memory, never on its disk, and each run leaves a machine-generated proof of deletion.

Where it runs

The pilot runs on hardware we control, with the heavy one-off reading of the archive done on a university GPU cluster. The application is containerised and moves between environments without code changes. The next step, as more offices join, is hosting in EU cloud regions. Personal data of tenants stays in the European Economic Area, under a data processing agreement with each office.

What it does not do yet

AdminCloud is in pilot with one property management office in Poland, and we will not pretend it is further along. The archive is in; the review queue and the first registers of buildings, tenants and rates work. Automated monthly billing, bank statement matching and correspondence are on the roadmap, built in that order. How accurately the model reads handwritten Polish notes is still being measured against a hand-labelled sample. We will publish the figure when we have it, not before.
