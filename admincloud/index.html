AdminCloud

Property management offices still run on binders. AdminCloud turns a paper archive into a working ledger of buildings, tenants, rates and charges.

  • Photograph the archive. A vision model reads and classifies every page.
  • Arithmetic checks the model. Totals, amounts in words and account numbers are verified, so a person only reviews what does not add up.
  • Built for other people's money. Every amount has an audit trail, and each office's data is kept apart.
From the pilotResult
Archive pages ingested (one office, one year) 1,210
Total facts recorded in the database 3,950
Cluster hosting the pilot (Raspberry Pi 4, 3 × ROCKPro64) 4 ARM64 nodes, 22 cores, 20 GB RAM, 1.1 TB storage

Now in pilot with one office in Poland. Next: more offices, hosted in EU cloud regions. Run a property management office with the archive still on paper? Write to karol.chlasta@warsawiq.com.
